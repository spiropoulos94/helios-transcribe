# GrechoAI

Εφαρμογή μετάφρασης με AI στα ελληνικά, φτιαγμένη με Next.js 16, TypeScript και Google Gemini 2.5 Flash. Ανέβασε αρχεία ήχου/βίντεο και πάρε ακριβείς ελληνικές μεταγραφές με αναγνώριση ομιλητών.

> 🌐 Αυτό είναι το ελληνικό αντίγραφο του README. Το αγγλικό πρωτότυπο βρίσκεται στο [README.md](../../README.md).

## Δυνατότητες

- 🎙️ **Μεταγραφή Ήχου & Βίντεο** - Υποστήριξη αρχείων MP3, WAV, MP4 και MOV
- 🇬🇷 **Υποστήριξη Ελληνικής Γλώσσας** - Βελτιστοποιημένο για ελληνική μεταγραφή με υψηλή ακρίβεια
- 👥 **Αναγνώριση Ομιλητών** - Αυτόματη αναγνώριση και σήμανση διαφορετικών ομιλητών
- 📚 **Βιβλιοθήκη Μεταγραφών** - Προβολή, διαχείριση και οργάνωση όλων των μεταγραφών σου
- 💾 **Τοπική Αποθήκευση** - Όλες οι μεταγραφές αποθηκεύονται τοπικά στον browser σου
- 📱 **Responsive Σχεδίαση** - Όμορφο UI που δουλεύει σε desktop, tablet και κινητό
- ⚡ **Γρήγορο & Αποδοτικό** - Τροφοδοτείται από Google Gemini 2.5 Flash για γρήγορα αποτελέσματα
- 🚀 **Παράλληλη Επεξεργασία** - Τα μεγάλα αρχεία ήχου επεξεργάζονται ταχύτερα με ταυτόχρονη επεξεργασία chunks

## Τεχνολογίες

- **Framework**: Next.js 16 με App Router
- **Γλώσσα**: TypeScript
- **Styling**: Tailwind CSS v4
- **AI Πάροχος**: Google Gemini 2.5 Flash (με OpenAI Whisper ως εναλλακτική)
- **Εικονίδια**: Lucide React
- **Αποθήκευση**: Browser localStorage

## Ξεκινώντας

### Προαπαιτούμενα

- Node.js (συνιστάται v18 ή νεότερη)
- Κλειδί Google Gemini API (παίρνεις από το [ai.google.dev](https://ai.google.dev))

### Εγκατάσταση

1. Κλωνοποίησε το repository:
   ```bash
   git clone <your-repo-url>
   cd grechoai
   ```

2. Εγκατάσταση dependencies:
   ```bash
   npm install
   ```

3. Ρύθμιση μεταβλητών περιβάλλοντος:
   - Αντίγραψε το `.env.local.example` σε `.env.local` (ή δημιούργησε νέο `.env.local`)
   - Πρόσθεσε το Gemini API key σου:
     ```
     GEMINI_API_KEY=your_api_key_here
     ```

4. Εκκίνηση development server:
   ```bash
   npm run dev
   ```

5. Άνοιξε το [http://localhost:3000](http://localhost:3000) στον browser σου

## Χρήση

### Μεταγραφή Αρχείου

1. Πήγαινε στην αρχική σελίδα
2. Κάνε κλικ «Upload File» ή σύρε-και-άσε αρχείο ήχου/βίντεο
3. Περίμενε το AI να επεξεργαστεί το αρχείο
4. Δες και διαχειρίσου τη μεταγραφή σου

### Διαχείριση Βιβλιοθήκης

1. Κάνε κλικ «Library» στο μενού πλοήγησης
2. Δες όλες τις αποθηκευμένες μεταγραφές σε προβολή πλέγματος
3. Κάνε κλικ σε οποιαδήποτε κάρτα μεταγραφής για πλήρεις λεπτομέρειες
4. Χρησιμοποίησε τα κουμπιά ενεργειών για αντιγραφή, λήψη ή διαγραφή μεταγραφών

## Ρύθμιση

### AI Πάροχοι

Η εφαρμογή υποστηρίζει πολλούς AI παρόχους με αυτόματο fallback:

1. **Google Gemini** (Κύριος) - Απαιτεί `GEMINI_API_KEY`
2. **OpenAI Whisper** (Εναλλακτικός) - Απαιτεί `OPENAI_API_KEY`

Πρόσθεσε τα API keys σου στο `.env.local`:

```env
GEMINI_API_KEY=your_gemini_key
OPENAI_API_KEY=your_openai_key  # Προαιρετικό fallback
```

### Προεπιλεγμένες Ρυθμίσεις Μεταγραφής

Βρίσκονται στο [app/api/transcribe/route.ts](../../app/api/transcribe/route.ts):

- **Γλώσσα-Στόχος**: Ελληνικά (`el`)
- **Διαρίκευση Ομιλητών (Diarization)**: Ενεργοποιημένη
- **Χρονοσφραγίδες**: Ενεργοποιημένες

### Επεξεργασία Ήχου για Μεγάλα Αρχεία

Για αρχεία ήχου πάνω από 10 λεπτά, η εφαρμογή μπορεί να χρησιμοποιήσει αυτόματα έξυπνο τεμαχισμό (chunking) όταν είναι ενεργοποιημένος:

- **Έξυπνο Μέγεθος Chunks**: Αυτόματος υπολογισμός του βέλτιστου μεγέθους (5-30 λεπτά) βάσει της διάρκειας του αρχείου
- **Επικάλυψη**: 10 δευτερόλεπτα μεταξύ των chunks για καλύτερη ακρίβεια
- **Παράλληλη Επεξεργασία**: Έως 3 chunks επεξεργάζονται ταυτόχρονα

Μπορείς να ρυθμίσεις το chunking στο `.env.local`:

```env
# Ενεργοποίηση αυτόματου chunking για μεγάλα αρχεία (προεπιλογή: true)
ENABLE_CHUNKING=true

# Μέγιστα ταυτόχρονα chunks (προεπιλογή: 3)
# 0 ή 1 = σειριακά (πιο αργό, πιο ασφαλές)
# 2-5 = περιορισμένα παράλληλα (ισορροπημένο)
# 6-10 = επιθετικά παράλληλα (πιο γρήγορο, πιο ριψοκίνδυνο)
# -1 = ΑΠΕΡΙΟΡΙΣΤΑ (ΜΕΓΙΣΤΗ ΤΑΧΥΤΗΤΑ - όλα τα chunks μαζί!)
MAX_CONCURRENT_CHUNKS=3
```

**Πώς Λειτουργεί το Έξυπνο Μέγεθος Chunks:**

Η εφαρμογή καθορίζει αυτόματα το βέλτιστο μέγεθος chunk βάσει της διάρκειας του αρχείου σου:

| Διάρκεια Αρχείου | Μέγεθος Chunk |
|--------------|------------|
| < 15 λεπτά | 5 λεπτά |
| 15-60 λεπτά | 10 λεπτά |
| 1-2 ώρες | 15 λεπτά |
| 2-3 ώρες | 20 λεπτά |
| 3+ ώρες | 30 λεπτά |

**Λειτουργίες Απόδοσης:**

| Λειτουργία | Ρύθμιση | Ταχύτητα | Χρήση API | Καλύτερο για |
|------|---------|-------|-----------|----------|
| Σειριακή | `0` ή `1` | Πιο αργή | Ελάχιστη | Αυστηρά rate limits |
| Ισορροπημένη | `3` (προεπιλογή) | 3x πιο γρήγορη | Μέτρια | Οι περισσότερες περιπτώσεις |
| Επιθετική | `6-10` | 6-10x πιο γρήγορη | Υψηλή | Γενναιόδωρα rate limits |
| **ΜΕΓΙΣΤΗ** | `-1` | **ΤΑΧΥΤΕΡΗ** | **Πολύ υψηλή** | **Χωρίς rate limits** |

**Παράδειγμα:** Αρχείο ήχου 90 λεπτών = 9 chunks των 10 λεπτών
- Σειριακά (`1`): ~90 λεπτά σύνολο
- Ισορροπημένα (`3`): ~30 λεπτά σύνολο (3x ταχύτερο)
- **Μέγιστο (`-1`)**: ~10 λεπτά σύνολο (9x ταχύτερο - όλα τα chunks επεξεργάζονται ταυτόχρονα)

**Οφέλη παράλληλης επεξεργασίας:**
- ⚡ **Δραματικά ταχύτερη μεταγραφή** - Έως N× επιτάχυνση όπου N = αριθμός chunks
- 🎯 **Ρυθμιζόμενη ταυτόχρονη εκτέλεση** - Έλεγχος βάσει των API rate limits σου
- 🧠 **Έξυπνο μέγεθος chunks** - Αυτόματη προσαρμογή στο μήκος του αρχείου
- 🔄 **Αυτόματη αναποκείδυνση (deduplication)** - Οι περιοχές επικάλυψης συγχωνεύονται έξυπνα
- 🛡️ **Ανθεκτικότητα σε σφάλματα** - Τα αποτυχημένα chunks δεν χαλάουν όλη τη μεταγραφή
